# okolos-extension — документация

Браузерная защита для эпохи AI-агентов: находит на страницах скрытые инструкции,
подсунутые твоему AI, проверяет ссылки и загрузки, следит за расширениями и
утёкшими паролями, а дружелюбный ассистент доводит до починки. Всё считается
локально — **история браузинга не покидает устройство**.

## Процесс

По правилам проекта (`~/.claude/CLAUDE.md`) путь до кода:

1. `superpowers:brainstorming` — закрыть развилки из `open-questions.md`
2. Спека → `docs/superpowers/specs/YYYY-MM-DD-<topic>-design.md`
3. План → `docs/superpowers/plans/YYYY-MM-DD-<feature>.md`
4. UX-сценарии → `docs/ux/scenarios.md` (обязательны до работы над UI)
5. Реализация (TDD, production-grade)

Ни один из шагов 1–5 не начат.
