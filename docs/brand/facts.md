# Факты

Что о продукте можно утверждать публично. Каждая строка несёт способ проверки —
файл, команду или число, полученное измерением. **Утверждения без проверки здесь
не место**, даже если они правдоподобны: этот файл существует, чтобы текст в
магазине и на экране не расходился с кодом.

Проверено 2026-08-08 на `de48b24`.

## Что продукт делает

| Утверждение | Чем подтверждено |
|---|---|
| Находит на странице текст, скрытый от человека, но видимый ассистенту | `packages/core-injection/src/stage1.ts`; корпус `corpora/injections` — 31 положительный, 34 отрицательных случая, оба языка |
| Обезвреживает найденное, не ломая страницу, и умеет вернуть как было | `apps/extension/src/content/sanitize.ts`, сценарий SCN-005 |
| Держит действие агента до решения человека | `packages/core-gate/src/decide.ts`, SCN-010 |
| Блокирует страницы по подписанному списку до их загрузки | `packages/core-feeds`, SCN-007 |
| Предупреждает о доменах-двойниках, включая кириллические подмены | `packages/core-lookalike`, SCN-006 |
| Судит о загрузках и никогда не выдаёт непроверенное за проверенное | `packages/core-download/src/judge.ts`, SCN-012 и SCN-013 |
| Следит за изменениями в установленных расширениях | `packages/core-extensions`, SCN-017 |
| Проверяет утечки по адресу почты и пароли по префиксу хеша | `packages/core-credential`, SCN-014 и SCN-015 |

## Чего продукт не делает

Это не оговорки мелким шрифтом, а часть обещания:

| Утверждение | Чем подтверждено |
|---|---|
| Не выпускает третью ступень на модели | Решение и измерение — `docs/licences.md`; модель помечает подписи для скринридеров как инструкции с уверенностью 1.00 |
| Не считает заблокированные угрозы и не рисует уровень защиты | Cross-screen rules в `docs/ux/screens.md` |
| Не отправляет историю браузинга | Один аудируемый узел `packages/net`; назначения перечислены ниже |
| Не хранит ничего дольше 90 дней | `RETENTION_DAYS = { journal: 90, outbound_log: 90 }` |
| Не удерживает действие, у которого нет формы и навигации | Записанный предел SCN-010 |
| Не может опознать агента, ведущего браузер снаружи, если тот снял флаг автоматизации | Записанный предел SCN-010, измерение `isTrusted` |

## Что уходит с устройства

Полный список назначений. Других нет, и это держит тест: запись в журнал
делается **до** запроса, и отказ записи отменяет запрос.

| Назначение | Что уходит | Зачем |
|---|---|---|
| `password-range` | **первые 5 символов** SHA-1-хеша пароля | проверка пароля по k-анонимности |
| `leak-lookup` | адрес почты | проверка утечек |
| `file-hash` | хеш файла | проверка загрузки |
| `feed-update` | ничего от пользователя | скачивание подписанного списка |
| `model-update` | ничего от пользователя | (не используется — ступень не выпускается) |
| `domain-status` | домен | публичная страница статуса, по запросу владельца |

Проверка пароля идёт по **префиксу** хеша (k-анонимность): сам пароль и его
полный хеш не отправляются. Полностью — [privacy.md](../privacy.md), и он
сверяется с кодом тестом, а не читается на веру.

## Разрешения, которые запрашивает расширение

`storage`, `alarms`, `activeTab`, `offscreen`, `declarativeNetRequest`,
`webNavigation`, `downloads`, `management`, плюс доступ к `http://*/*` и
`https://*/*`.

Широкий доступ к страницам нужен потому, что скрытый текст ищется **на любой
странице**, а не на списке избранных. Это же разрешение делает продукт
подозрительным по умолчанию — поэтому у него есть экран самоаудита, который
показывает журнал отправок и позволяет всё выгрузить и стереть.

## Языки

Интерфейс выпускается на русском по умолчанию (`default_locale: ru`) и на
английском. Каталог — `apps/extension/_locales`; отсутствующий ключ показывается
как `[ключ]`, а не пустотой, и это проверяется тестом.

**На 2026-08-08 из каталога говорят все одиннадцать рендереров интерфейса** —
экран блокировки, баннер, инспектор находки, гейт агента, попап, очередь,
доверенные домены, сравнение двойников, журнал, восстановление, опись
расширений и утечки. Из каталога говорят и все внутристраничные
предупреждения. Не переведены объяснения, которые фоновая часть пишет в журнал
(этап B-02c бэклога), поэтому утверждать «продукт на русском» целиком пока
нельзя, и здесь этого не написано.

Число ключей в каталоге меряется, а не переписывается:

```bash
python3 -c "import json;print(len(json.load(open('apps/extension/_locales/ru/messages.json'))))"
```

## Знак

Кольцо с точкой в центре: кольцо — периметр, за которым продукт следит, точка —
человек внутри него. Рисуется `tools/icons.mjs` из одного описания во все
размеры; тест сверяет закоммиченные байты с тем, что даёт генератор, и читает
настоящий размер из заголовка PNG.

Первым вариантом было кольцо с разрывом — «часть, оставленная тебе». На 16
пикселях любой разрыв читается как буква C: неверный инициал и идея хуже той,
что он нёс. Это свойство размера, а не угла, и проверяется оно только взглядом
на 16 пикселей.

## Как обновлять этот файл

Число здесь стареет молча — это его главная опасность. Правило: **любое число
берётся командой в момент правки**, а не переносится из прошлой версии. Если
команда не приводится, утверждение не факт, и ему здесь не место.
