# 02. Угрозы эпохи AI-агентов

Собрано 2026-08-03. Обосновывает ядро продукта (AI Shield, санитайзер, режим агента).

## 2.1 Prompt injection в дикой природе — это массовое явление

| Факт | Значение | Источник | Метка |
|---|---|---|---|
| Масштаб замера | просканировано **1.2 млрд URL** на **24.8 млн хостов** | «Indirect Prompt Injection in the Wild», arXiv 2604.27202 | [A] |
| Найдено | **15 300** подтверждённых внедрений на **11 700** страницах | там же | [A] |
| Организованность | небольшое число повторяющихся шаблонов даёт большинство случаев | там же | [A] |
| Носители | ~**70%** инструкций — в нерендеримых элементах (комментарии, заголовки, метаданные), нацелены на машину, а не человека | там же | [A] |
| Видимость для человека | лишь ~**5.1%** внедрений видимы; **58.6%** скрыты приёмами рендеринга | обзорные замеры 2026 | [B] |
| Восприимчивость моделей | до **8%** compliance у меньших моделей на plain-text входах; структурированное представление данных снижает восприимчивость | arXiv 2604.27202 | [A] |
| Цели атак | искажение выдачи модели, манипуляция репутацией, «защита контента», детект AI-ботов; мишени — краулеры, поисковые пайплайны, чат-боты поддержки, HR-воронки | там же | [A] |

**Что обосновывает:**
- Фича не спекулятивна: инъекции лежат на реальных страницах прямо сейчас.
- **70% в нерендеримом HTML** → разбор комментариев/`meta`/атрибутов обязателен.
- **Повторяющиеся шаблоны** → сигнатурная ступень эффективна и дёшева.
- **~95% невидимы** → DOM-vs-render diff как первая ступень покрывает почти всё.

## 2.2 Признание индустрии: изнутри не чинится

| Факт | Значение | Источник | Метка |
|---|---|---|---|
| Статус в OWASP | **LLM01:2025** — первый номер списка; формулируется как архитектурная уязвимость, а не дефект реализации | OWASP GenAI Security Project | [A] |
| Успех атак | до **84%** в агентных системах; продакшн-эксплойты с CVSS **>9.0** | обзор 2026 (MDPI Information 17(1):54) | [A] |
| Рост | **+340%** год к году — самая быстрорастущая категория атак | OWASP LLM Security Report 2026 | [B] |
| Позиция OpenAI | **13 февраля 2026** запущен Lockdown Mode для ChatGPT; публично признано, что prompt injection в AI-браузерах **«может никогда не быть полностью закрыт»** | OpenAI | [A] |
| Критические CVE | Microsoft Copilot CVSS 9.3, GitHub Copilot 9.6, Cursor IDE 9.8 | сводки 2025–2026 | [B] |

**Что обосновывает:** внешний независимый щит на уровне страницы — не костыль,
а необходимость, признанная самими вендорами AI.

## 2.3 Конкретные инциденты против браузерных ассистентов

| Инцидент | Суть | Источник | Метка |
|---|---|---|---|
| **Brave vs Perplexity Comet** | скрытые инструкции (белым по белому, HTML-комментарии) заставляли агента по запросу «суммируй страницу» выполнять кросс-сайтовые действия — вплоть до извлечения OTP из почты и доступа к банковскому порталу | Brave Security | [A] |
| **HashJack** (Cato CTRL) | первая известная indirect prompt injection против AI-ассистентов браузера через фрагмент URL | Cato Networks | [A] |
| **Claude-расширение** | уязвимость позволяла zero-click XSS prompt injection с любого сайта (март 2026) | The Hacker News | [B] |
| **ClawHub-скиллы** | **1 184+** вредоносных «скилла» распространяли Atomic Stealer и кейлоггеры (янв.–март 2026) | сводка инцидентов AI-агентов | [B] |
| **Рост payload'ов** | детекты длинных инъекционных нагрузок выросли ~**в 5 раз** с марта по май 2026; доля высокорисковых AI-взаимодействий удвоилась (1 из 50 → 1 из 25) | отраслевая телеметрия 2026 | [B] |
| **In-the-wild наблюдения** | web-based indirect prompt injection зафиксирован в живом трафике | Palo Alto Unit 42 | [A] |
| **CVE-2026-0628** | расширение с ограниченными правами эскалирует привилегии через панель Gemini в Chrome, внедряя код в привилегированный WebView | CVE | [A] |

**Что обосновывает:** сценарий «агент читает страницу → выполняет чужую команду»
уже реализован на практике, включая извлечение одноразовых кодов.

## 2.4 Насколько велика поверхность (кого защищаем)

| Факт | Значение | Источник | Метка |
|---|---|---|---|
| Доля Chrome | **69.65%** мирового использования (июнь 2026); Safari 15.31%, Edge 5.21%, Firefox 3.33% | сводки статистики браузеров | [B] |
| Агентные браузеры в компаниях | **27.7%** предприятий уже используют в проде (было ~0 два года назад) | Cyberhaven | [B] |
| Пользователи AI-браузеров | Comet (июль 2025) и Atlas (окт. 2025) — базы «в низких десятках миллионов» | отраслевые обзоры | [C] |
| Рынок AI-браузеров | $4.5 млрд (2024) → ~$76.8 млрд (2034), CAGR **32.8%** | market.us | [C] |
| Компании с AI-агентами | **79%** уже внедрили ту или иную агентную технологию | отраслевой опрос | [C] |

**Что обосновывает:** аудитория ещё не массовая (десятки миллионов), но растёт
быстрее всего в категории, и **защиты под неё нет**. Это окно для входа первыми.

## 2.5 Чем детектить: доступные модели

| Модель | Параметры | Пригодность | Источник | Метка |
|---|---|---|---|---|
| **Llama-Prompt-Guard-2-22M** | 22M, DeBERTa-xsmall | −75% латентности к 86M при минимальной потере качества; устойчивая к атакам токенизация (пробелы, фрагментация) | Meta / HuggingFace | [A] |
| Llama-Prompt-Guard-2-86M | 86M | выше качество, выше цена | Meta | [A] |
| ProtectAI `deberta-v3-base-prompt-injection-v2` | 184M | требует ~1 ГБ и GPU — тяжело для браузера | ProtectAI | [A] |
| Rebuff | — | **архивирован в мае 2025** | GitHub | [A] |
| Известное ограничение | guardrail-модели обходятся адверсариальными приёмами | «Bypassing LLM Guardrails», arXiv 2504.11168 | [A] |

**Что обосновывает:** классификатор — третья ступень, а не единственная. Первая
(невидимость) обходу не поддаётся: убрать сокрытие = показать текст человеку.
