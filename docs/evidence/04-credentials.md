# 04. Учётные данные, утечки, infostealer-логи

Собрано 2026-08-03. Обосновывает офлайн-проверку паролей и ставку на
infostealer-логи как на самый свежий класс данных.

## 4.1 Масштаб кражи учётных данных

| Факт | Значение | Источник | Метка |
|---|---|---|---|
| Украдено учётных данных за H1 2025 | **1.8 млрд**, **+800%** к предыдущему полугодию | сводный отчёт по infostealer-угрозам | [B] |
| За весь 2024 | **3.2 млрд**, из них **75%** — через инфостилеры | IBM X-Force | [A] |
| Паролей украдено малварью за 2025 | **>6 млрд** | Specops Breached Password Report 2026 | [A] |
| Credential harvesting как основной эффект инцидента | **29%** инцидентов | IBM Threat Intelligence Index | [A] |
| Учётные данные AI-сервисов | инфостилеры выкрали **~300 000** учёток ChatGPT (2025) | IBM X-Force | [A] |
| Связь с ransomware | у **54%** жертв ransomware домен присутствовал в дампах инфостилеров | Verizon DBIR | [A] |
| Консолидация экосистемы | вокруг LummaC2 и преемников; в 2026 ожидается дальнейший рост | Specops | [A] |

**Что обосновывает:**
- Инфостилер — доминирующий канал (75% украденного), и он **свежий**: логи
  появляются в обороте за часы-дни, а не годы, как публичные дампы.
- 54% связи с ransomware → показ инфостилер-находки пользователю имеет прямую
  практическую ценность, а не «информационную».

## 4.2 Доступность данных для проверки

| Источник | Что даёт | Условия | Метка |
|---|---|---|---|
| **HIBP Pwned Passwords** | ~1 млрд+ хэшей паролей (SHA-1 и NTLM) с частотой; k-anon API **и полный корпус на скачивание** | бесплатно, без ключа, **без рейт-лимита**, атрибуция не требуется | [A] |
| **HIBP breach metadata** | **1 022+** бреши: описания, даты, классы данных | бесплатно; данные под **CC BY 4.0**, атрибуция обязательна | [A] |
| HIBP stealer logs API | домены/почты из инфостилер-логов | только тариф Pro+ | [A] |
| **Hudson Rock Cavalier Community API** | поиск по email / домену / username в инфостилер-корпусе | **бесплатно, без ключа**, 50 запросов / 10 сек | [A] |
| XposedOrNot | breach-поиск, open-source API | бесплатный тариф + платный | [A] |
| DeHashed / LeakCheck / Snusbase | глубокий поиск, в т.ч. по паролям | ~$0.02–0.25/запрос; $9.99/мес; $5–16/мес | [B] |

**Что обосновывает:** самый ценный класс данных (инфостилер) доступен
**бесплатно**, а проверка паролей делается офлайн — глубина берётся инженерией,
а не бюджетом.

## 4.3 Приватность проверки

| Механизм | Свойство | Источник | Метка |
|---|---|---|---|
| k-anonymity (пароли) | шлём 5 hex-символов SHA-1, получаем ~800 суффиксов, матч локально; `Add-Padding: true` скрывает даже размер ответа | HIBP API docs | [A] |
| k-anonymity (email) | 6-символьный префикс SHA-1, тариф Pro+ | HIBP API docs | [A] |
| PSI/OPRF | Google Password Checkup: слепое вычисление на кривой `secp224r1` поверх ~4 млрд креденшелов; тот же подход в Apple iCloud Keychain | Google Security Blog | [A] |
| Полный офлайн | корпус Pwned Passwords скачивается целиком (`PwnedPasswordsDownloader`) | HIBP | [A] |

**Что обосновывает:** заявление «проверяем пароли, не отправляя ничего» —
техническая правда, а не маркетинг.

## 4.4 Разброс качества мониторинга у конкурентов

| Факт | Значение | Источник | Метка |
|---|---|---|---|
| Разрыв в находках | Aura — **18** dark-web алертов против **8** у ближайшего конкурента на том же профиле; в другом тесте 15 против 1 | сравнительные тесты 2026 (Cybernews, CyberInsider) | [B] |
| Уникальные находки | Aura обнаружила продажу Gmail-креденшелов на хакерском форуме, которую **пропустили все остальные** | там же | [B] |
| Пустые результаты | «многие протестированные сервисы не нашли вообще ничего» | там же | [B] |
| Скорость алерта | Aura — 3 минуты, Norton LifeLock — **9.2 часа** (mystery-shopper, 2025) | сравнительное исследование | [B] |
| Периодичность вместо непрерывности | Surfshark Alert запускает **периодические сканы**, а не непрерывный мониторинг | Cybernews review | [B] |
| Ложные срабатывания | отчёт «Reused Passwords» в 1Password даёт ложные позитивы | 1Password Community | [B] |

**Что обосновывает:** глубина и свежесть источников — это поле, где реально
выигрывают, а не паритетная функция.
