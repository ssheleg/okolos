## Как читать

**Шкала уверенности:**

| Метка | Значение |
|---|---|
| **[A]** | Первичный источник: отчёт вендора/регулятора, рецензируемая работа, официальная документация, замер по API |
| **[B]** | Вторичный: профильное СМИ или аналитика, ссылающиеся на первичный источник |
| **[C]** | Оценка рынка/агрегатор без раскрытой методики — использовать только как порядок величины |

**Правило конфликтов:** если оценки расходятся (типично для размеров рынка) —
приводим оба числа и помечаем расхождение, не выбираем удобное.

**Правило свежести:** данные о векторах атак живут ~6 месяцев. Файлы с меткой
старше полугода перепроверять перед принятием решений.

## Ограничения этого набора

- Trustpilot-скрейп заблокирован ботозащитой; отзывы Guardio взяты из G2 (n=4) и
  вторичных обзоров — это **не** репрезентативная выборка, помечено в
  [06-competitors.md](06-competitors.md).
- Полный отчёт Prowl не собрался (падал планировщик); использованы прямые вызовы
  инструментов каталога (DataForSEO, SpyFu) — сырые ответы воспроизводимы.
- Данные SpyFu по рекламе Guardio — снапшоты 2022 года; показывают стратегию, а
  не текущие ставки.
- Частотность запросов — Google Ads (DataForSEO), метрика намерения, а не числа
  пользователей.
