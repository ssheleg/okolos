# Pipeline brief — Okolos P0–P5 + public domain status

- **Дата:** 2026-08-04
- **Стадия:** 0 (intake) — бриф на замок
- **Модель прогона:** Opus 5 (подтверждено на preflight)

## 1. Задача

MV3-расширение (Chrome/Edge/Firefox) + тонкий Cloudflare Worker. Безопасность
браузинга в эпоху AI-агентов: детект и очистка скрытых инструкций для
AI-агентов, базовый анти-скам (ссылки, страницы, загрузки), утёкшие пароли и
данные, контроль расширений, дружелюбный ассистент, публичная страница статуса
домена с апелляциями. Опенсорс AGPL-3.0, английский UI, локальность
проверяема.
