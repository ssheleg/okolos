# Plan — Walking skeleton (M0 + M1 + срез M3/M4)

- **Спека:** [../specs/2026-08-04-m0-m1-skeleton-design.md](../specs/2026-08-04-m0-m1-skeleton-design.md)
- **Правило TDD:** падающий тест → подтвердить падение → минимальная реализация
  → подтвердить зелёный → коммит. Задача не закрыта, пока её гейт не показан
  красным на посаженном дефекте.

## Группы

```
T1 ─┬─ T2 ─┬─ T6 ─┐
    │      ├─ T3  ├─ T10 ─ T11 ─ T12
    │      ├─ T4  │
    └─ T5 ─┴─ T7 ─┤
           ├─ T8  │
           └─ T9 ─┘
```

Последовательные: T1, T2, T10, T11, T12. Параллельная группа A: T3, T4, T5.
Параллельная группа B: T6, T7, T8, T9 (файлы не пересекаются).

### T1 — Каркас воркспейса `[seq]`

**Файлы:** `package.json`, `pnpm-workspace.yaml`, `tsconfig.base.json`,
`eslint.config.js`, `vitest.config.ts`, `playwright.config.ts`,
`.github/workflows/ci.yml`

Скрипты корня: `build`, `test`, `test:e2e`, `lint`, `bench`, `ux:lint`.
ESLint flat config несёт два правила границы:

```js
// core-* не знает про браузер
{ files: ['packages/core-*/**/*.ts'],
  rules: { 'no-restricted-globals': ['error','window','document','chrome','browser','fetch'],
           'no-restricted-imports': ['error', { patterns: ['*/platform*','webextension-polyfill'] }] } }
// сеть только из транспорта
{ files: ['packages/**/*.ts','apps/**/*.ts'],
  ignores: ['packages/net/src/transport.ts'],
  rules: { 'no-restricted-globals': ['error','fetch','XMLHttpRequest','WebSocket','sendBeacon'] } }
```

**DoD:** `pnpm install && pnpm lint && pnpm test` проходит на пустом наборе;
CI-джоб запускается на push и содержит все шаги (пусть пока тривиальные).

### T2 — `packages/contracts` `[seq, зависит: T1]`

**Файлы:** `src/{verdict,snapshot,policy,rpc,index}.ts`, `src/*.test.ts`

TDD-порядок:
1. Тест: `decideAction` для 4 уровней уверенности даёт действия из таблицы
   спеки §3 → красный.
2. Тест-инвариант: вердикт, чьи улики все со `stage: 'model'`, **никогда** не

**DoD:** типы экспортируются, 100% ветвей `decideAction` покрыты, инвариант
модели зафиксирован тестом.

**Файлы:** `src/{schema,db,retention,export,index}.ts`, тесты рядом,

### T4 — `packages/net` `[группа A, зависит: T2, T3]`

**Файлы:** `src/{request,redactor,audit,transport,index}.ts`, тесты.

TDD-порядок:
1. Тест: `request()` пишет `AuditEntry` **до** вызова транспорта (проверяется
   порядком вызовов на моке) → красный.

**DoD:** `transport.ts` — единственный файл во всём репозитории, где
встречается `fetch`; проверяется T11.

### T6 — `packages/core-injection` ступень 1 `[группа B, зависит: T2]`

**Файлы:** `src/{stage1,index}.ts`, `src/stage1.test.ts`,
`corpora/injections/*.json`, `corpora/clean/*.json`

Чистая функция `detectHidden(c: PageCandidates, now: string, ids: () => string): Verdict[]`.
Корпус: минимум 20 позитивов (белым по белому, `display:none`, 1px,
комментарий, `meta`, `alt`, zero-width, Unicode-тег) и 20 негативов (a11y-текст
для скринридеров, скрытые табы, JSON-LD разметка).

**DoD:** recall ≥ 90% на позитивах, 0 срабатываний на негативах корпуса; ни
одного обращения к `document` (проверяется T11).
